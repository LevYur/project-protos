# Project Protos

Репозиторий содержит protobuf-контракты и сгенерированный Go-код для gRPC-взаимодействия сервисов проекта **E-Commerce Microservices Platform**.

Основной репозиторий проекта:

```text
https://github.com/LevYur/project
```

Контракты вынесены в отдельный репозиторий, чтобы отделить описание API от реализации сервисов и обеспечить единый источник истины для межсервисного взаимодействия.

---

# Назначение репозитория

В микросервисной архитектуре сервисы взаимодействуют друг с другом через gRPC.

Данный репозиторий содержит:

* protobuf-контракты;
* сгенерированный Go-код;
* Makefile для генерации кода.

Основной проект использует этот репозиторий как источник gRPC API.

---

# Структура проекта

```text
project-protos/
│
├── cart/
│   └── external/
│       ├── proto/
│       ├── gen/
│       └── Makefile
│
└── products/
    └── external/
        ├── proto/
        ├── gen/
        └── Makefile
```

---

# Контракты

## Cart Service

Содержит описание gRPC API для сервиса корзины.

Основные операции:

* AddToCart;
* RemoveFromCart;
* GetCart;
* ClearCart.

---

## Products Service

Содержит описание gRPC API сервиса товаров.

Используется Cart Service для получения актуальной информации о товарах.

Основные операции:

* InfoForCart.

---

# Генерация кода

Для генерации Go-кода используется `protoc`.

Пример генерации для Cart Service:

```bash
cd cart/external
make generate
```

Пример генерации для Products Service:

```bash
cd products/external
make generate
```

# Почему protobuf вынесены в отдельный репозиторий

Такой подход позволяет:

* отделить описание API от реализации сервисов;
* использовать единый контракт для всех сервисов;
* независимо развивать реализацию и описание API;
* избежать дублирования `.proto`-файлов;
* упростить поддержку и версионирование контрактов.

---

# Использование

Основной проект использует данный репозиторий как зависимость для генерации и подключения gRPC-контрактов.

При изменении `.proto`-файлов необходимо повторно сгенерировать Go-код и обновить зависимость в основном проекте.
